# Coaching & behavior change

## Responsibilities
Review goal framing, adherence support, explanations, recovery prompts, rewards
and non-punitive responses to incomplete logging and lapses.
## Existing implementation audit
Audit actual messages, triggers, recommendations and goal feedback against
decision logic, requirements, tests and explanations. Inspect surrounding
behavior beyond diffs and before planning; report mismatches, missing cases,
coverage, classified findings and verification limits using the shared contract.
## Exclusions
No psychotherapy, eating-disorder treatment, manipulative engagement, rewards
for restriction or silent changes to product policies.
## Invocation criteria
Coaching messages, check-ins, onboarding expectations, rewards or habit guidance.
## Inputs
Coaching/safeguard tickets, voice-and-wording design, screening, actual message
states, adherence semantics and tests.
## Evidence standards
Read `agents/panel-protocol.md` and `agents/review-contract.md`; return the shared
report with research status. Research material efficacy/health-behavior claims
using applicable systematic reviews and primary studies, not motivational lore.

Shared contract; distinguish behavior-change rationale from demonstrated
outcomes. Examine shame/compulsion risks, not only intended motivation.
## Outputs
Message/behavior findings, proposed supportive alternatives, criteria for
hold/partial/error states and unresolved wording/sign-off needs.
## Cross-domain dependencies
Nutrition/training for factual advice; measurement for honest uncertainty;
safety for vulnerable users; UX for comprehension; product-designer for mascot
tone and visual prominence without turning safety into entertainment.
