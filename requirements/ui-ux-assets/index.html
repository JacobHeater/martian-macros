Martian Macros UI/UX reference library

CurrentEvery view and reusable component of the app as built, drawn as HTML with its states (MM-211). Drawn on 2026-10-11 from the source and the screenshot tests.

These sheets show what exists. They approve nothing, they are not the app, and where a sheet and a requirement disagree the requirement stands. Each sheet says what limits it.

Coverage

coverage.json lists every widget file in apps/mobile/lib/src with the frame that draws it, the states drawn, its requirements, how it was checked and what limits it. mm req fails when a widget file is missing from it, when an entry names a file or a frame that does not exist, or when an entry is incomplete.

Reading the sheets

Open this file in a browser; nothing is fetched and no build is needed. The app’s two fonts are read from apps/mobile/assets/fonts/, so keep the library inside the repository; without them the system font is used. If your browser refuses local fonts or scripts from a file, serve the repository instead: python -m http.server in the repository root, then open /requirements/ui-ux-assets/.

On every sheet the Theme switch redraws it in Martian, Dark or Light, and the Text switch enlarges it (approximately: the whole frame scales, where the app scales only text). Segments, chips, switches, check boxes, choice cards and folded sections answer a tap; some frames open a sheet or a dialog. Numbers are made-up fixture data, and nothing is calculated.

The convention, and what to do when a view or component is added or changed, is in README.md.
